## How it works

1. Something ordinary happens during your day.
2. **Roll the dice** to decide how many reps you do.
3. Complete the challenge against a **beeping workout timer**.
4. Repeat, and fitness becomes part of your daily routine.

## Features

- Dice-based rep generator with a card-game feel
- A workout timer with audio cues
- **Installable PWA** with a web manifest and service worker, so it works offline
- Responsive, mobile-first design

## Tech stack

HTML, CSS, and vanilla JavaScript, plus a service worker and web manifest for
the PWA.

## Run locally

```bash
git clone https://github.com/dean1234533/Repping-It.git
cd Repping-It
npx serve .   # a local server is needed for the service worker
```
